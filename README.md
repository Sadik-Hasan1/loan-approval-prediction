# Loan Approval Prediction

A machine-learning project that explores applicant and financial attributes to predict whether a loan application is likely to be **Approved** or **Rejected**.

## Project workflow

The notebook includes:
1. Loading the loan-approval CSV (or a ZIP containing it) in Google Colab.
2. Exploratory data analysis: missing values, duplicates, target distribution, categorical values, and numerical summaries.
3. Checking asset values and removing rows with negative asset values.
4. Splitting the data into training, validation, and test sets with stratification.
5. Preprocessing numerical features (median imputation and standard scaling) and categorical features (most-frequent imputation and one-hot encoding).
6. Training and comparing Logistic Regression, Decision Tree, and Random Forest models.
7. Evaluating the selected model on a held-out test set.
8. Reviewing feature importance and a learning curve.
9. Running an interactive Gradio prediction demo in Colab.
10. Saving a model bundle and final model-comparison results from the notebook.

## Dataset

The notebook expects a CSV containing the columns used in the project, including `loan_id`, `no_of_dependents`, `education`, `self_employed`, `income_annum`, `loan_amount`, `loan_term`, `cibil_score`, asset-value columns, and `loan_status`.

Upload the dataset in Google Colab when the first cell prompts you. The dataset itself is not included in this repository bundle.

## Run in Google Colab

1. Open `Loan_Approval_Prediction.ipynb` in Google Colab.
2. Run the cells in order from top to bottom.
3. When prompted, upload the loan-approval CSV or ZIP file.
4. Run the model-training and evaluation cells before launching the Gradio demo.

The Gradio share URL generated by a Colab session is temporary; it is not a permanent deployment URL.

## Important limitations

This is an educational machine-learning demonstration, not a real bank decision system. Predictions and displayed probabilities are model estimates, not guarantees of loan approval. Model performance can be affected by dataset quality, leakage, sampling, and differences between the dataset and real-world applicants. Do not use this demo as the sole basis for financial decisions.
